# RB-017: Restart database primary (last resort)

## Triage
1. WARNING: this is the last resort for a hung database that no longer accepts any connection.
2. A slow database, a database with a connection timeout, high cpu or an unresponsive database that still answers queries does NOT justify a restart: use RB-007 or RB-008 first.

## Mitigation
1. `restart_db_primary` restarts the database primary. It drops all connections for 2-4 minutes, fails every checkout in that time and is never automatic. A DBA must be present and break-glass applies during the freeze.

## Verification
1. Connections re-established and replication caught up.

## Escalation
Never execute without the DBA lead and the incident commander agreeing in writing.
