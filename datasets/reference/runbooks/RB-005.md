# RB-005: TLS certificate expiry and handshake failures

## Triage
1. Look for x509 or handshake errors in the logs of the failing component and note the certificate expiry timestamp.
2. An error step exactly at a round time (00:00) with no deploy points to expiry, not to a bad release.

## Mitigation
1. Issue and install a new certificate with `renew_cert` (medium risk).
2. Reload the component only if the certificate is not hot-reloaded.

## Verification
1. Handshake errors stop and error_rate returns to baseline within 5 minutes.

## Escalation
Security on-call if the certificate was revoked rather than expired.
